# 支援與回報 / Support

## 一般問題

請先閱讀 [README](README.md)、[開發指引](docs/DEVELOPMENT_GUIDE.md) 及現有 issues。可重現的程式錯誤請使用 GitHub 的 bug report 表格；功能建議請使用 feature request 表格。

只可使用合成資料、placeholder identifier 及已遮蔽的 log。不要在公開 issue、截圖或附件加入真實商戶資料、電郵、JWT、token、Cloudflare identifier、資源名稱、私人 URL、原始圖片或模型。

## 安全問題

漏洞請按 [Security Policy](SECURITY.md) 使用 repository 的私人漏洞回報功能。不要在公開 issue 披露可利用細節或敏感資料。

## Support in English

Check the README, development guide, and existing issues first. Use the GitHub issue forms for reproducible bugs or bounded feature requests. Submit only synthetic data, placeholders, and redacted logs. Report vulnerabilities privately through the repository Security tab.

This public repository does not provide support for private deployments, production records, provider accounts, or customer-specific configuration.
